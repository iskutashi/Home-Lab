# Home-Lab

This repository contains my complete IT Support and SysAdmin home lab environment.  
I use this lab to practice real-world enterprise skills including Active Directory, DNS, DHCP, Group Policy, mail systems, networking, ticketing workflows, and security fundamentals.

Each project inside this Home-Lab is documented with:
- Architecture and environment details  
- Objectives  
- Implementation steps  
- Troubleshooting (Problem → Investigation → Root Cause → Resolution → Verification)  
- Screenshots and evidence  
- Lessons learned  
- Improvements and next steps  

This portfolio is designed to reflect how real IT Support and SysAdmin work is done in production environments.

## Repository Structure

### 1. MailServer-hMailServer
Internal mail server built using hMailServer and Thunderbird.  
Includes DNS configuration, SMTP/IMAP setup, firewall rules, and full troubleshooting.

### 2. ActiveDirectory-Enterprise
Enterprise-level AD environment with multiple branches, departments, OUs, users, groups, and GPOs.

### 3. GPO-Configurations
All Group Policy work including security baselines, drive mappings, software restrictions, and user/computer policies.

### 4. Networking-Labs
Routing, subnetting, DNS, DHCP, VLANs, and connectivity troubleshooting.

### 5. Ticketing-Practice
Simulated IT Support tickets with full troubleshooting workflows.
