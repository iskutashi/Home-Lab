# MailServer-hMailServer

This project documents the setup, configuration, and troubleshooting of an internal mail server using hMailServer inside my Active Directory home lab.

## What This Lab Covers

- Installing and configuring hMailServer  
- Creating internal mailboxes  
- Setting up SMTP and IMAP  
- DNS configuration for internal mail routing  
- Thunderbird client configuration  
- Firewall rules  
- Troubleshooting connectivity and authentication  
- Evidence of successful mail delivery
